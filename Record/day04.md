### 总结

#### git使用流程

1. 首先调用 `git status` 查看相关文件状态，视情况使用`git add\git commit`
2. 选择和检查使用的分支是否正确
   - `git branch`检查分支的情况
   - 在主分支 使用 `git pull origin xxx`来进行同步和拉去
   - `git branch -b xxxx`创建一个新的分支并转移到新分支进行开发
